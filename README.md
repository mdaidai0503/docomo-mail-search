# docomo-mail-search

ドコモメール検索 iPhone対応試作版 v0.2。

## 現在できること

- ファイルから `.eml` と文字情報のあるPDFを手動取込
- 送信者・件名・本文・PDF本文のキーワード検索、AND/OR、期間指定
- IndexedDBによる端末内保存
- Safariの「ホーム画面に追加」

メールファイルをアプリのサーバーへ送信する処理はありません。PDF解析用ライブラリは外部CDNから取得します。

## 公開と使い方

1. このリポジトリの Settings → Pages を開く。
2. Sourceを Deploy from a branch、Branchを main、フォルダを /(root) にして Save。
3. 公開完了後、Pages画面に表示されたURLをiPhoneのSafariで開く。
4. 必要に応じて共有メニューから「ホーム画面に追加」。
5. 「ファイル」に保存したメールやPDFを取り込み、検索する。

GitHub Pagesの利用可否はリポジトリの公開範囲と契約プランに依存します。公開用ファイルにメール本文やパスワードを含めないでください。

## 制約と確認状況

ドコモメールへの自動接続・自動同期は未実装です。複雑なMIMEメールの日本語件名・本文や添付ファイルの解析は暫定実装で、正しく検索できない場合があります。画像だけのPDFのOCRには対応していません。

PDFライブラリの読込にはネット接続が必要です。ブラウザデータの消去等で保存データが失われる場合があるため、元ファイルを保管してください。PDFの日付はメールの受信日ではなくファイルの更新日を使用します。

既存の `docomo_mail_iphone_v0.2.zip` のアプリ本体を引き継いだ段階です。iPhone実機動作とドコモメールの実ファイルでの検索精度は未確認です。
