ドコモメール検索 iPhone 試作版 v0.2

現状：iPhone Safariで使用する静的Webアプリ。ホスティング（GitHub Pagesなど）に配置後、Safariで開き「ホーム画面に追加」。
取込：iPhoneのファイルアプリに保存した .eml と、文字情報を持つPDFを手動選択。
検索：送信者・件名・本文・PDF内文字、期間、AND/OR。
保存：ブラウザのIndexedDBに端末内保存。サーバーにはアップロードしない。
制約：ドコモメール自動同期は未実装。MIMEエンコードや添付を含む複雑なEMLの解析は暫定。画像PDFのOCRは未対応。PDFライブラリの読み込みにはネット接続が必要。
安全：IMAPパスワードはこのアプリに入力しないこと。ブラウザ保存データはSafariのデータ消去で失われる場合があります。
次段階：安全なサーバー側IMAP取得、認証、PDF OCR、同期、iPhoneからのアクセス制御を追加。
